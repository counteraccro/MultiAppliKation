# Le nom : MultiAppliKation

## Le jeu de mots

« Multi » + « Appli » + « Kation » : **plusieurs applis**.
Le projet vise loin : si les tables plaisent, d'autres activités s'ajouteront
dans la même application. Le nom dit « multiplication » aujourd'hui et
« plusieurs applis » demain.

## Pourquoi deux p

« Appli » s'écrit avec deux p. Écrit **MultiAppliKation** :
- le mot « Appli » se voit, le jeu de mots saute aux yeux ;
- l'enfant lit un mot inventé, pas « multiplication » mal écrit
  (elle apprend aussi l'orthographe à 9 ans).

## Sous l'icône

iOS coupe les noms vers 11-12 caractères (« MultiAppliK… »).
Nom court sous l'icône : **MultiAppli** (10 caractères).
