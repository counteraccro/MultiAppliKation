# Architecture : une boîte à activités

Le nom le promet : d'autres activités viendront après les tables
(divisions, conjugaison…). On le prévoit dès le départ ; ça ne coûte presque
rien maintenant et évite de tout refaire au deuxième module.

## Parcours

Qui joue ? → choix de l'activité → l'activité.

## Activité = module à part

Chaque activité a ses écrans, ses règles et ses données.
Ajouter une activité ne doit rien casser dans les autres.

## Briques communes

Partagées par toutes les activités :
- pavé de réponse (tactile + clavier) ;
- chrono ;
- étoiles ;
- écran de résultat ;
- révision intelligente (boîtes de Leitner), valable pour toute activité
  de type question / réponse ;
- profils et sauvegarde.
